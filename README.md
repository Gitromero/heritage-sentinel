Project Description:

Heritage Sentinel is a CSC-4880 project that spans the entire semester, with the goal of developing an AI system that can assess damage to cultural heritage artifacts, plan possible restoration steps, and track artifact provenance. The project is intended to be split into various modules that will be developed and integrated throughout the semester. Our primary algorithm will initially be a uniform Breadth-First Search (BFS), designed with modularity in mind. This foundation is built to provide a strong starting point, with reusable and adaptable code that can serve various purposes as the project continues to develop.
